## Authoring notes

1. **Subject-name parity with Grade 1**: must use **identical** subject strings (`اللغة العربية`, `English`, `الرياضيات`, `التربية الإسلامية`). The audit R10 rule is cross-grade because `Subject` is keyed by `(name, gradeLevel)` but `questionText` uniqueness is by subject name only — i.e. an Arabic question in Grade 1 must not duplicate an Arabic question in Grade 2.

2. **Mandatory minimums per lesson** (spec §10):
   - ≥10 questions (audit hard floor is 8)
   - ≥1 difficulty-3
   - ≥3 distinct sub-skills
   - All MCQ correctAnswer ∈ options
   - All FILL_BLANK has exactly one `___`
   - All ORDERING token multiset matches options multiset
   - TRUE_FALSE: correctAnswer ∈ {صح, خطأ, True, False}, options=null

3. **Cross-grade R10 hazards already identified**:
   - باب (Grade 1 letter Ba) vs Grade 2 madd lesson — addressed via lexical change
   - Common letters/numerals — Grade 2 should use lesson-vocab specific examples
   - Surahs الفلق / المسد appear in BOTH grades — Grade 2 must use different question stems

4. **Defer**: imageUrls / imageUrl / audioUrl arrays stay empty (`[]` / null) per the spec's deferred-assets pass. R12/R13/R15-R18 stay warning-level for Grade 2 as well.

5. **Idempotent build script**: one `Manhaji/scripts/curriculum/_build_grade2.py` that writes all 8 JSON files in a single run. Re-running produces a byte-identical output (no random shuffles).
